⏰ 发条 ClockWork

自动跟随法定节假日的闹钟与日历：法定工作日才响，休息日静音。另含世界时钟、倒计时、计时器/秒表、打卡、日期计算器与桌面挂件。

隐私政策 使用条款 技术支持

主要功能

  • 闹钟：普通 / 法定工作日 / 轮班 / 区间（久坐、喝水提醒）/ 指定日期 / 特殊周期（大小周）/ 年度 / 月度，支持标签颜色、自定义铃声与请假跳过。
  • 日历：公历农历、二十四节气、节假日与调休标注，本月上班/休息统计。
  • 世界时钟：常用城市实时时差、昼夜显示与时间换算（专业版）。
  • 倒计时 / 打卡：重要日子进度与习惯打卡，支持桌面挂件（专业版）。
  • 计时器 / 秒表 / 日期计算器：多实例计时、计次秒表、日期推算。
  • 版本备份：每日快照，可保留 7/30/60/90 天，可选同步到你自己的 iCloud。
