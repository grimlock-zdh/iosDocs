⏰ 发条 ClockWork

自动跟随法定节假日的闹钟与日历：法定工作日才响，休息日静音。另含世界时钟、倒计时、打卡与桌面挂件。

隐私政策 使用条款 技术支持

主要功能

  • 闹钟：普通 / 法定工作日 / 轮班 / 区间（久坐、喝水提醒，专业版）/ 指定日期 / 特殊周期（大小周）/ 年度 / 月度，支持自定义随机铃声池、铃声截取与请假跳过。
  • 日历：公历农历、二十四节气、节假日与调休标注，本月上班/休息统计。
  • 世界时钟：常用城市实时时差、昼夜显示与时间换算（免费）。
  • 倒计时：目标日期、重复周期与定期提醒，可分配小/中/大挂件组（专业版）。
  • 打卡：习惯打卡、月/年统计与打卡挂件（专业版）。
  • 桌面挂件：月历 / 周历 / 日历、世界时钟、倒计时、打卡。
  • 版本备份：每日快照，可保留 7/15 天，可选同步到你自己的 iCloud。

免费版包含闹钟、日历、世界时钟的基础功能，并提供 30 天专业版试用。专业版：¥20 一次买断（非消耗型内购，终身有效），解锁倒计时、打卡、区间闹钟、响铃日历请假与不限量随机铃声。
